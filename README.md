# Antiquity
Antiquity is a Minecraft mod for 26.2+ that adds a variety of new features based on the historical Antiquity period. 
It includes new blocks, items, and gameplay mechanics that allow players to explore and experience the world of ancient civilizations.  

## Features
- Blocks:
  - Kiln Bricks 
  - Layered Stone Roads (Inspired by Ancient Roman Roads)
    - Layered Cobblestone Road
    - Layered Blackstone Road
  - Marble Blocks (Inspired by Ancient Roman Architecture)
- Weapons:
  - Gladius Weapon (Inspired by Ancient Roman Swords)
  - Glaive Weapon (Inspired by Minecraft Dungeons' Glaive)

## About
